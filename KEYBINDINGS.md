# Hyprland Keybindings Cheatsheet

> `Super` = tecla Windows/Command

## Aplicaciones

| Atajo | Accion |
|---|---|
| `Super + Enter` | Terminal (Ghostty) |
| `Super + B` | Navegador (Brave) |
| `Super + E` | Gestor de archivos (Nemo) |
| `Super + D` | Lanzador de apps (Rofi) |
| `Super + V` | Historial del portapapeles |
| `Super + N` | Panel de notificaciones |
| `Super + L` | Bloquear pantalla |

## Capturas de pantalla

| Atajo | Accion |
|---|---|
| `Print` | Captura de area (seleccionar) + editar |
| `Shift + Print` | Captura de pantalla completa + editar |
| `Super + Print` | Captura de area y guardar en ~/captures/ |

## Ventanas

| Atajo | Accion |
|---|---|
| `Super + Q` | Cerrar ventana activa |
| `Super + F` | Pantalla completa |
| `Super + Space` | Alternar flotante/tiling |
| `Super + P` | Modo pseudo (flotante dentro de tiling) |
| `Super + S` | Alternar split horizontal/vertical |
| `Super + Shift + Q` | Salir de Hyprland |

## Foco (mover entre ventanas)

| Atajo | Accion |
|---|---|
| `Super + Flechas` | Mover foco (izq/der/arriba/abajo) |
| `Super + H/J/K` | Mover foco (vim-style: izq/abajo/arriba) |

## Mover ventanas

| Atajo | Accion |
|---|---|
| `Super + Shift + Flechas` | Mover ventana en esa direccion |
| `Super + Shift + H/J/K/L` | Mover ventana (vim-style) |

## Redimensionar ventanas

| Atajo | Accion |
|---|---|
| `Super + Ctrl + Flechas` | Redimensionar ventana activa |
| `Super + Click derecho` | Redimensionar arrastrando |
| `Super + Click izquierdo` | Mover ventana arrastrando |
| Arrastrar bordes | Redimensionar (ventanas flotantes) |

## Groups (modo stacked/tabbed)

> Apila ventanas en el mismo espacio con una barra de pestañas arriba (equivalente al modo stacked de i3).

| Atajo | Accion |
|---|---|
| `Super + G` | Crear / disolver grupo con la ventana activa |
| `Super + Tab` | Siguiente ventana del grupo |
| `Super + Shift + Tab` | Anterior ventana del grupo |
| `Super + Alt + Flechas` | Meter ventana vecina al grupo en esa direccion |
| `Super + Alt + O` | Sacar ventana activa del grupo |
| `Super + Alt + L` | Bloquear grupo (no auto-anadir nuevas ventanas) |

## Workspaces (escritorios virtuales)

| Atajo | Accion |
|---|---|
| `Super + 1-9, 0` | Ir al workspace 1-10 |
| `Super + Shift + 1-9, 0` | Mover ventana al workspace 1-10 |
| `Super + Scroll raton` | Navegar entre workspaces |

## Workspaces por defecto

| Workspace | App |
|---|---|
| 2 | Navegadores (Brave, Firefox, Chrome) |
| 3 | VS Code |
| 4 | Spotify |

## Multimedia

| Atajo | Accion |
|---|---|
| `Vol +/-` | Subir/bajar volumen (5%) |
| `Mute` | Silenciar/activar audio |
| `Play/Pause` | Reproducir/pausar media |
| `Next/Prev` | Siguiente/anterior pista |
| `Brillo +/-` | Subir/bajar brillo (5%) |

## Waybar (barra superior)

| Modulo | Click |
|---|---|
| Reloj | Click para formato largo (fecha completa) |
| Volumen | Click abre Pavucontrol |
| Bluetooth | Click abre Blueman |
| Tiempo | Click abre wttr.in |

| Captura | Click para captura de area |
| Notificaciones | Click abre panel de notificaciones |
